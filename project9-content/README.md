# Проект 9: Автопублікація контенту (зоомагазини)

> Сирі замітки/новини → LLM формує Telegram-пост → публікація
> з трекінгом стану (що вже опубліковано).

## Склад
- `sources/` — 5 сирих джерел (ринок, порада тижня, огляд товару, акція, факти)
- `content-autopublisher.js` — генерація поста + публікація
- `published.json` — стан публікацій (автоматично ведеться)

## Режими
```
node content-autopublisher.js --draft    # показати згенерований пост (без публікації)
node content-autopublisher.js --publish  # згенерувати й надіслати в Telegram
node content-autopublisher.js --list     # список: опубліковано / у черзі
```

## Результат (24.10.2026)
- Опубліковано: source1-market.txt (пост про ріст ринку зоотоварів на 15%, преміум-сегмент, розумні годівниці) → Telegram.
- У черзі: source2–source5 (щоразу новий запуск публікує наступне джерело).

## Ключова ідея
- **LLM** — перетворення сирого матеріалу в емоційний, структурований пост із хэштегами (обмеження 900 символів).
- **Детермінований стан** — «опубліковано/у черзі» зберігається в JSON, тому дублі публікацій виключені.
- Поєднується з n8n schedule: щодня автоматично «беремо наступне неопубліковане джерело → публікуємо».
