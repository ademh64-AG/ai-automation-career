# Проект 5: Скоринг резюме кандидатів (LLM)

> Оцінювання резюме проти опису вакансії: бал 1–10, вердикт
> (yes/maybe/no), сильні сторони, прогалини.

## Склад
- `vacancy.txt` — опис вакансії (Спеціаліст з автоматизації процесів)
- `resumes/` — 4 демо-резюме (сильне, середнє, слабке, + наше AI-резюме)
- `resume-scorer.js` — LLM-оцінювання + CSV/HTML-звіт + Telegram

|---|---|---|

Середній бал: 5.3. Звіти: `reports/scoring-2026-10-24.{csv,html}`.

## Як використовувати
```
node resume-scorer.js            # звіт
node resume-scorer.js --send     # + топ-3 у Telegram
```

## Для чого це демонструє
- Промпт-інженерія з жорсткою JSON-схемою відповіді.
- Зв’язок з реальною бізнес-задачею (HR/рекрутинг) — прискорення первинного відбору.
- Інструмент «чесний»: може оцінити і наше власне резюме (8/10), що добре показує самокритичність.
