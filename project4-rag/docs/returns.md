# Повернення та обмін

## Умови повернення
- Повернення товару можливе протягом 14 днів з дати поставки.
- Товар повинен бути з непошкодженою упаковкою та збереженими пломбами.
- Повернення оформлюється накладною та актом приймання-передачі.

## Не підлягає поверненню
- Алкогольна продукція з пошкодженою акцизною маркою.
- Товар з простроченим терміном придатності.

## Компенсація браку
- При виявленні браку акт складається протягом 48 годин після отримання.
- Брак замінюється або компенсується протягом 7 робочих днів.
